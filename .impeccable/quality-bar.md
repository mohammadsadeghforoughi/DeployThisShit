# Quality bar: shipping manifest console

- **Native devices:** carbon rail, ruled register, route stamp, machine-value slips, in-plane inspector, and a single moving checkpoint rule.
- **Frame:** one continuous paper work surface against a carbon navigation edge; information belongs to a document, not a grid of floating cards.
- **Depth:** flat by default. Use rules, sticky planes, and dark-light contrast; reserve ambient shadow for the authentication sheet.
- **Lettering:** compressed editorial grotesk for authority and restrained monospace only for machine data.
- **Ornament density:** one stamped route note and sparse logistics marks; no fake barcodes, decorative grain, or costume labels.
- **Motion:** progress travels left-to-right only while a release is changing state; controls respond with a one-pixel lift.
- **Ceiling test:** the first viewport must reveal application, route, release, health, server condition, and a reversible operation without opening another page.
